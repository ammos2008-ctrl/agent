Папка с проектом в облаке, у которой есть память: она помнит каждое изменение файлов. Можно вернуться к любой прошлой версии.

## Полезные слова

| Слово | Что значит |
|---|---|
| Репозиторий | Папка проекта с историей изменений |
| Commit | «Снимок» изменений с подписью, что поменялось |
| Branch (ветка) | Копия проекта для экспериментов, не ломающая основную версию |
| Pull Request | Предложение влить изменения из ветки в основную версию |
| README | Файл-описание проекта, который GitHub показывает на главной странице |
